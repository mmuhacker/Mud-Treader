## 🔧 التثبيت

### 1. تثبيت Python
```bash
pkg install python -y
```

### 2. تثبيت المكتبات
```bash
pip install websocket-client
pip install rich
pip install arabic-reshaper
pip install "python-bidi==0.4.2"
```

### 3. نسخ ملف البوت
```bash
cp /sdcard/mud.tr.py ~/mud.tr.py
```

### 4. إنشاء اختصار التشغيل
```bash
echo 'alias tr="python ~/mud.tr.py"' >> ~/.bashrc
source ~/.bashrc
```

## 📱 شرح القوائم

### الصفحة الرئيسية
```
1 → تشغيل البوت
2 → الإعدادات
3 → إغلاق البرنامج
```

### قائمة الإعدادات (3 خطوات)

**الخطوة 1 - اختيار السوق:**
```
1-9 → اختر السوق المطلوب
0   → رجوع للصفحة الرئيسية
```

**الخطوة 2 - اختيار الاستراتيجية:**
```
1-5 → اختر الاستراتيجية
0   → رجوع للسوق (الخطوة السابقة)
x   → رجوع للصفحة الرئيسية
```

**الخطوة 3 - إعدادات الصفقة:**
```
Enter → متابعة لإدخال المبلغ والمدة
0     → رجوع للاستراتيجية
x     → رجوع للصفحة الرئيسية
```

### قائمة التحكم (أثناء التشغيل)
```
اضغط m → فتح قائمة التحكم

1 → متابعة تشغيل البوت
2 → تغيير الإعدادات
3 → إغلاق البرنامج
```

## 🎯 الاستراتيجيات

### 1. RSI + المتوسط المتحرك
- يحسب مؤشر القوة النسبية (RSI)
- يقارن السعر مع المتوسط المتحرك (MA)
- شراء عند RSI أقل من 30 وسعر فوق MA
- بيع عند RSI أعلى من 70 وسعر تحت MA

### 2. MACD
- يحسب الفرق بين المتوسطين EMA12 و EMA26
- شراء عند تقاطع MACD فوق خط الإشارة
- بيع عند تقاطع MACD تحت خط الإشارة

### 3. Bollinger Bands
- يرسم نطاق سعري علوي وسفلي
- شراء عند لمس السعر للنطاق السفلي
- بيع عند لمس السعر للنطاق العلوي

### 4. دعم ومقاومة
- يحسب أعلى وأدنى سعر في آخر 20 شمعة
- شراء عند اقتراب السعر من الدعم
- بيع عند اقتراب السعر من المقاومة

### 5. مجمّع (الكل) ⭐ موصى به
- يجمع نتائج كل الاستراتيجيات الأربع
- يدخل الصفقة فقط عند تأكيد 65% أو أكثر
- أعلى دقة وأقل مخاطرة

## 📊 لوحة التحكم

```
🤖 الحالة        → آخر حدث في البوت
📍 السوق         → الزوج المختار حالياً
🎯 الاستراتيجية  → الاستراتيجية النشطة
💰 الرصيد        → رصيد الحساب
📈 الربح         → صافي الربح/الخسارة
حركة السعر       → شارت مبسط للحركة
📊 المؤشرات      → RSI, MA, MACD, BB
⚡ الإشارة       → توصية الشراء أو البيع
💪 قوة الإشارة   → شريط من 0% إلى 100%
💵 السعر الحالي  → السعر الفوري المباشر
```

### ألوان الإشارة:
- 🟢 **أخضر** → شراء قوي (CALL) - صعود مؤكد
- 🔵 **أزرق** → شراء متوسط (CALL) - صعود محتمل
- 🔴 **أحمر** → بيع قوي (PUT) - هبوط مؤكد
- 🟠 **برتقالي** → بيع متوسط (PUT) - هبوط محتمل
- ⏳ **أبيض** → انتظار - لا توجد فرصة
