## 🔧 التثبيت

</div>
### 1. تثبيت Python
```bash
pkg install python -y
```

### 2. تثبيت المكتبات
```bash
pip install websocket-client rich arabic-reshaper "python-bidi==0.4.2"
```

### 3. تحميل البوت مباشرة من GitHub
```bash
curl -o ~/mud_tr.py https://raw.githubusercontent.com/mmuhacker/Mud-Treader/main/mud_tr.py
```

## 🚀 التشغيل

### بالاختصار (بعد إعداده)
```bash
tr
```

### أو بالأمر الكامل
```bash
python ~/mud_tr.py
```

### إعداد الاختصار (مرة واحدة فقط)
```bash
echo "alias tr='python ~/mud_tr.py'" >> ~/.bashrc && source ~/.bashrc

## 🔐 استخراج التوكن

### Deriv
1. سجّل دخولك على [deriv.com](https://deriv.com)
2. اذهب إلى **الإعدادات** (Settings)
3. اختر **Security & Safety**
4. اختر **API Token**
5. اضغط **Create new token**
6. اختر صلاحية **Read** و **Trade**
7. انسخ التوكن الظاهر

> مثال: `uYgU8m4B3vXvE8z`

---

### Binance
1. سجّل دخولك على [binance.com](https://binance.com)
2. اضغط على صورة ملفك الشخصي
3. اختر **API Management**
4. اضغط **Create API**
5. اختر **System generated**
6. أدخل اسماً واضغط **Next**
7. أكمل التحقق الأمني
8. انسخ **API Key**

> ملاحظة: احفظ الـ Secret Key فوراً لأنه لن يظهر مجدداً

---

### MetaTrader 5
1. افتح تطبيق **MetaTrader 5**
2. اذهب إلى **Tools** ← **Options**
3. اختر تبويب **Server**
4. انسخ رقم **Login**
5. أدخله في البوت عند الطلب

## 📱 شرح القوائم

### الصفحة الرئيسية
```
1 → تشغيل البوت
2 → الإعدادات
3 → إغلاق البرنامج
```

### قائمة الإعدادات (7 خطوات)

| الخطوة | الخيارات |
|--------|----------|
| 1 - المنصة | 1-3 للاختيار، 0 للرئيسية |
| 2 - التوكن | إدخال التوكن، 0 للسابق، x للرئيسية |
| 3 - السوق | 1-9 للاختيار، 0 للسابق، x للرئيسية |
| 4 - الفريم الزمني | 1-5 للاختيار، 0 للسابق، x للرئيسية |
| 5 - الاستراتيجية | 1-5 للاختيار، 0 للسابق، x للرئيسية |
| 6 - قوة الإشارة | 1-4 للاختيار، 0 للسابق، x للرئيسية |
| 7 - الصفقة | إدخال المبلغ والمدة، 0 للسابق، x للرئيسية |

### أثناء التشغيل
```
Ctrl + C → فتح قائمة التحكم
```

### قائمة التحكم
```

<div align="center">
 
**Binance**

</div>

1. سجّل دخولك على [binance.com](https://binance.com)
2. اضغط على صورة ملفك الشخصي
3. اختر **API Management**
4. اضغط **Create API**
5. اختر **System generated**
6. أدخل اسماً للمفتاح واضغط **Next**
7. أكمل التحقق الأمني

> ملاحظة: احفظ الـ Secret Key فوراً لأنه لن يظهر مجدداً

> مثال على شكل التوكن: `vmPUZE6mv9SD5VNHk4HlWFsOr6aKE2zvsw0MuIgwCIPy6utIco14y7Ju91duEh8A`

<div align="center">
 
**MetaTrader 5**

</div>

3. اختر تبويب **Server**
4. ستجد **Login** (رقم الحساب) — انسخه
5. أدخله في البوت عند الطلب

> ملاحظة: البوت يستخدم بيانات السوق من Yahoo Finance للعرض، والتداول الحقيقي يحتاج اتصالاً مباشراً بالوسيط

> مثال على شكل التوكن: `12345678`
